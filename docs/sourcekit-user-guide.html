What You Need Before You Start

Browser

  • Use Google Chrome for consistent login and capture behavior.

Account access

  • Use an approved SourceKit account with search permissions.
  • Ensure search quota and external provider keys are active.

Have these details ready

  • Role context: ML Engineer + target company Anthropic.
  • Target-company shortlist (for example: Anthropic, OpenAI, DeepMind, Stripe, Datadog).
  • Target-repository signals (for example: PyTorch, vLLM, Ray, model serving, distributed training).
  • Webset criteria text for reusable recurring sourcing workflows.

Troubleshooting

Strategy build remains in progress
Continue in Results tab and refine with query, repo signals, and filters while strategy service recovers.
No engineers found
Broaden the query by removing one or two company constraints and keeping technical repo signals.
Webset create shows Failed to fetch
Check provider keys and account limits, then retry from the same saved criteria.
Completed run not visible in Results
Open History and select the completed run entry to reload ranked candidates.
Export disabled or empty
Confirm results are loaded and active filters are not removing all rows.
